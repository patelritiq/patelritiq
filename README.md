# 🚀 Featured Projects

### 📊 Data Analytics & Machine Learning

**[Government Scheme & MSME Analytics](https://github.com/patelritiq/Government-Scheme-MSME-Analytics-MPSEDC)**  
State-level analytics dashboard built with **Power BI + Python** analyzing **19,288+ records across 50+ districts** to monitor welfare schemes and MSME growth.

**[SmartFace Attendance](https://github.com/patelritiq/SmartFace-Attendance)**  
Real-time **face recognition attendance system** using OpenCV & KNN with **100+ samples per user** and automated CSV attendance logging.

**[DS Assignment – Zeotap](https://github.com/patelritiq/DS_Assignment_Zeotap)**  
Customer segmentation system using **K-Means clustering** on behavioral transaction data to identify 5 customer clusters.
